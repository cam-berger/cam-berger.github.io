GFM-Interp

What has a scientific foundation model actually learned? In a masked genome model, I traced how it finds splice sites it was never trained to find.

The problem

Scientific foundation models make accurate predictions, but nobody can say what they learned in order to make them. When a genome model finds a splice site, is it using biology, or a shortcut that happens to work? The answer decides whether we can trust it on sequences it has never seen.

What I built

A measurement and a toolkit. I defined a measurement for the model’s splice-site decision, then adapted interpretability methods built for language models to a genome model, tracing the nodes and edges that carry the decision.

How it works

  1. 1

    Measure

    Define a logit-difference measurement for the model’s splice-site decision.

  2. 2

    Attribute

    Rank the attention heads and paths that carry it, and decompose them with QK/OV analysis.

  3. 3

    Decompose

    Fourier-decompose the positional signal, which exposes a period-three component.

Result

The model reconstructs splice sites from boundary content and a learned three-nucleotide positional wave, with no splice-specific training.

On 400 sealed test sequences, corrupting the paired acceptor changes the masked-donor margin by 0.872 logit units (95% CI 0.771–0.969); matched controls give 0.007 and 0.005. Ablating the two heads the scan found, L3H1 and L2H15, removes 81.6% of that coupling, more than any of 400 random head pairs. Nested activation-patching interventions then assign four causal roles: positional geometry supplies an address, early heads and MLPs build an acceptor-side payload, L3H1 writes it to the donor, and later heads deliver it. Deleting the learned period-3 component cuts coupling from 0.946 to 0.026 logit units. The core is real but not self-sufficient: 90% faithfulness takes 64 of the 103 measured nodes.

What broke, what’s next

Some of what the model learned is not robust. Simple perturbations remove its confidence, and some well-known biology is only weakly encoded. That looks like shortcut learning rather than robust representation, and it suggests a better representation of genomic information would be both more accurate and more robust. The period-three component is where I would start building that representation theory.

Why this belongs in Multisensory Intelligence

Genomic sequence is a modality with no words in it. The group studies how models learn across modalities like that, and this work is an instrument for looking inside one. It speaks directly to the group’s theory of how transformers represent structure: induction heads on Markov chains at NeurIPS 2025, and the emergence of multimodal alignment at ICML 2025.
